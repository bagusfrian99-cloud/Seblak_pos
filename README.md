# 📸 Photobooth PWA (Progressive Web App)

Aplikasi Photobooth modern berbasis Progressive Web App (PWA) yang siap di-host di GitHub Pages secara gratis.

## ✨ Fitur Utama
- 📱 **Support PWA (Progressive Web App):** Dapat diinstal di HP (Android/iOS) atau Desktop langsung dari browser.
- 🎞️ **Mode Photobooth 4-Cut Strip:** Mengambil 4 foto beruntun otomatis dan menggabungkannya dalam frame strip photobooth klasik.
- 🎨 **Pilihan Warna Frame:** Ubah warna background frame strip (Putih, Dark, Pastel Pink, Pastel Blue, Yellow).
- ⏱️ **Timer Hitung Mundur & Flash:** Pilihan timer (3s / 5s) disertai angka countdown di layar dan efek kilat flash saat foto diambil.
- 🎭 **Filter Real-time:** Hitam-Putih (B&W), Vintage Sepia, Cyberpunk, High Contrast, & Invert.
- 🪞 **Mode Cermin (Mirror Toggle):** Membalikkan tampilan seperti cermin kamera selfie.
- 💾 **Unduh Hasil PNG:** Simpan hasil foto resolusi tinggi ke galeri/penyimpanan lokal.

## 🚀 Cara Upload ke GitHub Pages

1. **Extract file ZIP ini.**
2. Buat repositori baru di GitHub (misal: `photobooth-pwa`), set **Public**.
3. Unggah seluruh file (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, dan folder `icons/`) ke repositori tersebut.
4. Masuk ke **Settings** > **Pages** di repositori GitHub Anda.
5. Ubah Branch menjadi `main` / `master`, lalu klik **Save**.
6. Akses link HTTPS GitHub Pages Anda (misal: `https://username.github.io/photobooth-pwa/`).
